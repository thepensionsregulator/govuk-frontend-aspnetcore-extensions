# Accordion

This implements the [Accordion component](https://github.com/gunndabad/govuk-frontend-aspnetcore/blob/main/docs/components/accordion.md) from the GOV.UK Design System. For examples see [ASP.NET syntax for the Accordion component](https://github.com/gunndabad/govuk-frontend-aspnetcore/blob/main/docs/components/accordion.md).

## Umbraco

You can add an accordion component to a block grid or block list in Umbraco. For examples of this component in use, see the 'Accordion' page in the Umbraco example app.

There are separate GOV.UK and TPR versions of the accordion component. If the block grid or block list you're adding to uses a data type like 'GOV.UK Block grid' you'll get the GOV.UK accordion. If you're using a TPR data type like 'TPR Block grid' you'll get the TPR accordion. The TPR accordion is the same as the GOV.UK accordion, except that it allows images (and other TPR components may be allowed in future versions).
